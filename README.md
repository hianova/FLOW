## 💻 Command-Line Interface (CLI Usage)

FLOW provides two streamlined binaries: `flowc` (the declarative compiler) and `flowy` (the autonomic assistant and runtime brain).

### 1. Zero-Trivia Execution & Compilation (`flowy`)

```sh
# 1. Compile and run a .flow specification instantly (auto-mounts companion .fvec)
flowy run examples/rank.flow

# 2. Compile .flow directly to a standalone native binary (SMT formally verified)
flowy build examples/rank.flow -o build/rank

# 3. Explain real-time scheduling and hardware decisions (0% hallucination)
flowy why

# 4. Inspect system invariants, AST, and companion lockfiles
flowy inspect why
flowy inspect timeline
flowy inspect bottleneck
flowy inspect audit

# 5. Read 《The FLOW Book》in the interactive terminal viewer (16 Chapters)
flowy book all
flowy book 16   # Chapter 16: Four Frontier Pillars & Control Theory Defenses

# 6. Autonomic interactive REPL shell
flowy shell
```

### 2. High-Performance Compiler (`flowc`)

```sh
# 1. Zero-coldstart emission: apply pre-baked SMT-certified .fvec lockfile (<50ns)
flowc examples/rank.flow -o generated/rank.c --apply-fvec .flow/vecs/hft_ultra_low_latency.fvec

# 2. Compile specification and lock architecture vector
flowc examples/project.flow -o generated/project.c --lock .flow/vecs/project_prod.fvec

# 3. Multi-backend emission (C, Rust, Python, MLIR, LLVM IR)
flowc examples/rank.flow -o generated/rank.c \
    --target-c-header generated/rank.h \
    --target-rust generated/rank.rs \
    --target-python generated/rank.py \
    --target-mlir generated/rank.mlir \
    --target-llvm-ir generated/rank.ll
```

### 3. Phase Space Jet Bundles & Symplectic Physics (`flowy jet`)

```sh

# 2. Run symplectic numerical simulation with Velocity Verlet integration

# 3. Render 60x20 ASCII phase portrait trajectory (q, p) in terminal
```
