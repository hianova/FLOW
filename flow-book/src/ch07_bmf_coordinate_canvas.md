# 第七章：BMF 離散座標畫布 (從隨機退火到 1-Bit 座標畫布、代數流形交集與上位連鎖)

> 「隨機退火搜尋只是開拓期的過渡工具；現代 FLOW 將 BMF 定位為離散座標畫布與流形代數交集，以多面體求解與連鎖群翻轉跨越上位效應壁壘。」

---

## 7.1 為什麼盲目隨機遺傳搜尋已死？

在早期的 BMF 探索中，依賴大量隨機位元翻轉尋優。然而在具有強大上位效應（Epistasis）的系統架構中：
$$\text{Lock Type = Lockless} \iff \text{Memory Reclaimer = QSBR}$$
隨機突變將有 99% 的機率製造出不相容的崩潰狀態。

現代 FLOW 將 BMF 徹底轉型為**「1-Bit 離散座標畫布（1-Bit Coordinate Canvas）」**：
$$\mathbf{g} \in \{0, 1\}^{64}$$
它不再是靠盲目猜測的基因組，而是高維連續約束流形投影到底層硬體暫存器上的布林切片。

---

## 7.2 流形交集與超位元原子翻轉

當兩個子系統的約束流形求交集：
$$\mathcal{M}_{\text{inter}} = \mathcal{M}_A \cap \mathcal{M}_B$$
流形代數直接在邊界推導出不可分割的連鎖群（Linkage Groups）。系統將相關位元綁定為「超級位元（Super-Bit）」，在單一 CPU 週期內同步原子翻轉，100% 避免無效中間態。
