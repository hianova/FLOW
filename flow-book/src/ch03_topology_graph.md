# 第三章：拓樸圖譜 (將程式碼降維成可推算的依賴約束流形)

> 「軟體的架構不是文字檔目錄的堆疊，而是一張高維拓樸圖。在 FLOW 中，程式碼被降維成可直接進行圖論運算、親和性分析與遙測附著的活體神經圖譜。」

---

## 3.1 拓樸節點與分層防火牆

FLOW 在二進位核心中維護完整的活體拓樸圖（`FlowTopologyGraph`），包含五大層級：
- **Layer 0 (Core)**：編譯器大腦、SMT 最高法院、QSBR 世代管理器。
- **Layer 1 (Interface)**：ABI 適配器、硬體原語驅動、邊界網關。
- **Layer 2 (Plugin)**：可動態插拔的組件與演算法外掛。
- **Layer 3 (Intent)**：使用者的 `.flow` 意圖節點與數據流。
- **Layer 4 (Doc-as-Topology)**：活體文檔與哲學命題節點。

嚴格保證**高層依賴低層，核心零向上洩漏**；所有跨層調用皆受 SMT 形式化架構審計保護。

---

## 3.2 潛意識神經遙測附著

拓樸節點不是死的符號，而是即時掛載神經遙測（Subconscious Neural Telemetry）的感受野：
- L3 Cache Miss Rate
- QSBR 世代排空佇列深度
- 馬達力矩比率與接觸阻抗

當某個節點的遙測熱點超過基線時，拓樸圖立即向因果推論大腦（Flowy）呈報異常，驅動架構幾何自愈。
