# 第十三章：QSBR 零鎖熱替換 (微秒級世代指針遷移與 Watchdog 隔離)

> 「在高並發伺服器中，獲取哪怕一把讀寫鎖都會引發災難性的快取一致性風暴。FLOW QSBR 實現了讀取路徑零原子寫入、熱替換微秒級無損遷移。」

---

## 13.1 QSBR 靜態世代演進

FLOW 採用 QSBR（Quiescent State Based Reclamation）無鎖熱替換架構：
- 讀取路徑**零原子指令、零記憶體柵障（Memory Barrier）**，讀取吞吐量高達 390M ops/s。
- 寫入者在發射新架構時，僅需原子替換全域世代指標。

---

## 13.2 Epoch Watchdog 掉隊者隔離

若某個讀者執行緒因中斷或死迴圈滯留在舊世代，看門狗透過 `mprotect` 對舊記憶體頁面施加隔離保護，並捕獲信號進行優雅降級，確保熱替換過程 0 停機、0 掉包。
